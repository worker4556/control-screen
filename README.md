### 👁️ Control Screen

Система интерактивного управления жестами и анализа позы тела в реальном времени. Проект использует веб-камеру и технологии машинного зрения **MediaPipe** для распознавания движений рук, жестов и анализа положения тела, адаптированных под автоматизацию и управление операционной системой **macOS**. 

### ✨ Основной функционал

### 1. 🫱 Детекция свайпов (SwipeDetector)

* **Механика:** Отслеживает горизонтальные движения (свайпы) кончика указательного пальца.
* **Действие:** Переключает рабочие столы macOS (влево/вправо) при обнаружении быстрого жеста.

### 2. 🖐️ Распознавание жестов рук

Модель распознает специфические жесты и мгновенно привязывает их к системным событиям: 

* **Closed Fist (Кулак):** Включение или выключение звука (Mute/Unmute).
* **Victory (Мир/Ножницы):** Быстрый запуск браузера *Firefox*.
* **Thumb Up (Большой палец вверх):** Эмуляция скролла страницы вверх.
* **Thumb Down (Большой палец вниз):** Эмуляция скролла страницы вниз.

### 3. 🧘 Анализ позы тела (BodyAnalyzer)

Непрерывный мониторинг ключевых точек (плечи, нос, запястья): 

* **Детекция тряски:** Реагирует на сильное хаотичное движение тела и выводит тревожное предупреждение на экран.
* **Сигнал SOS:** Автоматически распознает полностью поднятые вверх руки как призыв о помощи.

### 4. 🍏 Системная интеграция с macOS

* Прямое управление громкостью и аудио-микшером через скрипты **AppleScript**.
* Эмуляция системных горячих клавиш для плавного переключения рабочих пространств.

### 5. 💻 Главный цикл и UI

* Захват и обработка видеопотока с камеры в режиме реального времени с минимальной задержкой.
* Визуальный интерфейс на базе **OpenCV**: наложение скелетных масок, отображение текущего жеста и уведомлений о тревогах прямо поверх видео.

### 🛠️ Установка

Выполните последовательно следующие команды в терминале: 

1. **Клонируйте репозиторий:** 

bash

git clone <URL>

Используйте код с осторожностью.
2. **Перейдите в директорию проекта:** 

bash

cd control-screen

Используйте код с осторожностью.
3. **Установите необходимые зависимости:** 

bash

npm install

Используйте код с осторожностью.

### 🚀 Использование

Для запуска системы управления введите в консоли: 

bash

npm start

Используйте код с осторожностью.

После этого откроется окно предпросмотра камеры. Для корректной работы системы управления рабочими столами и звуком убедитесь, что терминалу/приложению выданы **разрешения на доступ к камере и Универсальному доступу (Accessibility)** в настройках конфиденциальности macOS.
