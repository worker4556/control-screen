Этот код реализует систему управления жестами и анализа позы тела с использованием камеры и библиотеки MediaPipe. Основной функционал:

Детекция свайпов (SwipeDetector):

Определяет горизонтальные движения (свайпы) указательного пальца.
Реагирует на свайпы вправо и влево, переключая рабочие столы macOS.
Распознавание жестов рук:

Использует модель MediaPipe для распознавания жестов, таких как "Closed Fist", "Victory", "Thumb Up", "Thumb Down".
Выполняет действия в зависимости от жеста:
Closed Fist: Включение/выключение звука.
Victory: Запуск браузера Firefox.
Thumb Up: Скролл вверх.
Thumb Down: Скролл вниз.
Анализ позы тела (BodyAnalyzer):

Определяет ключевые точки тела (плечи, нос, запястья).
Реагирует на:
Сильную тряску тела (выводит тревогу).
Поднятые руки (сигнал SOS).
Системные функции для macOS:

Управление звуком через AppleScript.
Переключение рабочих столов с помощью системных горячих клавиш.
Главный цикл:

Захватывает кадры с камеры.
Выполняет анализ позы и жестов в реальном времени.
Отображает результаты (жесты, тревоги) на экране.
Интерфейс:

Использует OpenCV для отображения видео с наложением информации о жестах и позах.




Установка
Клонируйте репозиторий:
git clone <URL>

Перейдите в директорию проекта:
cd control-screen

Установите зависимости:
npm install

Использование
Запустите приложение с помощью команды:

npm start
